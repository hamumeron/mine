💡 高FPSのための追加ヒント (UIのみ、手動で対応)
• Chrome: chrome://flags → 「Override software rendering list」をEnabled
• Chrome: chrome://settings → ハードウェアアクセラレーション → ON
• ゲーム内オプション → グラフィック → 「Fast」選択でFPS+20〜40%
• ゲーム内オプション → 描画距離 → 8チャンクでFPS+30〜50%
• ゲーム内 → パーティクル: Minimal / スムーズ照明: OFF でさらに高速化
このランチャーが実際にやること
「高速化」と書いてあるだけで何もしないUIとは違い、以下の処理を実際に実行します。
01
ZIP解凍 実装済み
JSZipでブラウザ内展開。全ファイルをBlob URLに変換してiframeで完全動作させる
02
HTMLを解析 実装済み
eaglercraftXOptsを正規表現で検出。存在しなければ新規挿入する
03
オプション注入 実装済み
keepAliveHack / finishOnSwap / enforceVSync などを設定値に応じて注入する
04
Blob起動 実装済み
パッチ済みHTMLをBlob URLとしてiframeに読み込む。外部サーバー不要
⚠️ 正直な限界
• WASMバイナリ自体の最適化はできません (コンパイル済みのため)
• WebGL APIはブラウザが制御するため外部から変更不可
• iframeのサンドボックスによりSharedArrayBufferが使えない場合がある
• 最大のFPS向上はゲーム内オプションの設定変更によるものが大きい
• 本当に効く: keepAliveHack (バックグラウンド時のFPS低下防止), enforceVSync (WASM特有のイベントループ詰まり防止)
